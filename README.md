## Запуск
Откройте `index.html` двойным щелчком. Все стили, фото, иконки и аудио находятся локально. Для проверки в режиме сервера откройте терминал в этой папке: `python -m http.server 8000`, затем `http://localhost:8000`. Python нужен только для этого способа запуска, сайт не требует сборки.

## Состав
- `index.html`, `style.css`, `script.js`: семантическая страница, адаптивность, меню, темы, калькулятор и демонстрационная заявка.
- `images/`: SVG-иконки, WebP-изображение студии, два авторских синтезированных WAV-демо.
- `design/index.html`: просмотр четырех SVG-макетов; `design/figma-plugin/`: импорт редактируемых фреймов в Figma.
- `docs/technical-rider.txt`: технический райдер.
- `docs/DEFENSE-RU.md`: выступление и ответы на теорию.
- `docs/PUBLISH-RU.md`: публикация на GitHub Pages с сохранением истории Git.
- `docs/CHECKLIST-RU.md`: соответствие критериям и оставшиеся проверки.
- `docs/verification.json`: результаты статического аудита и контрастности.
- `.git/`: локальная история разработки, не удаляйте перед отправкой через Git.

## Возможности
Dark Mode включен по умолчанию. Переключатель в подвале сохраняет тему. На мобильном экране меню сворачивается, CTA закреплен снизу. CSS использует Grid/Flexbox, относительные единицы и основной breakpoint 1024 px. В HTML нет div и таблиц для верстки. Поддерживаются видимый фокус, Skip to content и reduced motion.

Форма проверяет обязательные поля нативными средствами HTML/CSS. Минимальная дата задается JavaScript; телефон — минимум 10 цифр, email — type=email. Стоимость: vocal 8,000 ₸/h, mixing 12,000 ₸/h, podcast 15,000 ₸/h; инженер для vocal +5,000 ₸/h, для остальных включен. Заявка сохраняется на устройстве, скачивается в JSON и удаляется кнопкой. Это учебная демонстрация без сервера бронирования, проверки свободных слотов и реальной отправки студии.

Локальная реализация, SVG-макеты и материалы подготовлены. Создание облачного файла Figma, выполнение Contrast-плагина и публикация GitHub Pages не завершены. ## Повторяемые проверки
`node tests/behavior.cjs` — логика JavaScript с моделируемым DOM (требуется современный Node с RegExp v). `python tests/audit.py` — статический HTML/CSS-аудит, ссылки, WAV и расчет контраста (стандартная библиотека Python). `node --check script.js` — синтаксис. Эти команды не заменяют браузерную проверку.
