# Защита: WAVEFORM Studio

## Выступление на 2–3 минуты
Я разработал WAVEFORM — учебный сайт студии записи музыки и подкастов. Его задача — показать услуги, техническое оснащение и стоимость сессии, а затем помочь посетителю подготовить заявку.

Главный экран содержит фотографию акустической зоны и CTA Book studio time. Далее расположены три карточки услуг: Vocal recording, Track mixing и Turnkey podcast. Раздел оборудования описывает сигнальный тракт и позволяет скачать райдер. Есть почасовые тарифы и два собственных синтезированных аудиодемо.

Я использовал Mobile First: базовые стили описывают мобильный экран, а при ширине от 1024 пикселей карточки становятся тремя колонками. Для раскладки применены Grid и Flexbox; размеры и отступы заданы преимущественно в rem и процентах. Семантическая структура состоит из header, nav, main, section, article и footer. Контентных div нет.

Темная тема включена по умолчанию, светлая выбирается в подвале. Для текста рассчитаны контрастные сочетания. У интерактивных элементов есть видимый фокус, подписи и скругленные углы. На мобильном экране CTA расположен внизу, в зоне большого пальца.

Форма запрашивает тип услуги, дату, длительность, инженера, имя, телефон и email. Обязательные поля и форматы проверяются HTML, состояние ошибок выделяется CSS. JavaScript рассчитывает стоимость и сохраняет демонстрационную заявку только на устройстве. Например: два часа вокальной записи стоят 16,000 тенге, с инженером — 26,000 тенге; два часа сведения — 24,000 тенге с уже включенным инженером.

История Git состоит из последовательных смысловых коммитов. Четыре локальных макета подготовлены для импорта в Figma: 390 и 1440 пикселей, в двух темах. После импорта необходимо показать реальные фреймы и сетки. Публикация на GitHub Pages и визуальная проверка на устройствах требуют завершения перед итоговой демонстрацией.

## Ответы на вопросы

**Что такое Mobile First?** Сначала проектируется компактный интерфейс и пишутся его базовые стили. Расширения для больших экранов добавляются через min-width. Это помогает сохранить важный контент и ясную структуру на телефоне.

**Чем Grid отличается от Flexbox?** Grid управляет строками и колонками одновременно; им построена сетка карточек. Flexbox распределяет элементы преимущественно вдоль одной оси; используется для навигации, кнопок и небольших групп.

**Почему семантические теги?** Они описывают роль контента для браузера, поисковых систем и вспомогательных технологий. Section — тематический раздел с заголовком, article — самостоятельная карточка, nav — группа навигационных ссылок.

**Зачем box-sizing: border-box?** Padding и border включаются в заданную ширину элемента, что упрощает расчет размеров и предотвращает неожиданное расширение блоков.

**Почему rem?** Единица rem зависит от размера корневого шрифта. При изменении пользовательских настроек текст и связанные отступы масштабируются согласованно. Проценты и minmax(0,1fr) позволяют колонкам сжиматься без переполнения.

**Как работают media queries?** Базовая сетка имеет одну колонку. При @media(min-width:1024px) задаются три колонки, горизонтальная навигация и распределение крупных секций по сетке.

**Что такое Thumb Zone?** Область экрана, куда удобнее дотянуться большим пальцем при удержании телефона одной рукой. Важная кнопка размещена у нижнего края, а действия формы следуют за полями.

**Что такое WCAG-контраст?** Отношение относительной яркости текста и фона. Для обычного текста уровня AA ориентир 4,5:1. В проекте рассчитаны основные пары обеих тем; это не равнозначно полной сертификации доступности или запуску Figma Contrast.

**Что такое squircle?** Форма между квадратом и кругом с более плавным переходом кривизны. В Figma-импорте задан corner smoothing 65%; в CSS используется corner-shape:squircle с обычным border-radius как запасным вариантом.

**Чем HTML-валидация отличается от CSS?** required, type=email, pattern и min задают ограничения в HTML. CSS :user-invalid и :user-valid оформляют состояние. CSS сам по себе не определяет правила и не отправляет данные. Серверная проверка нужна в реальном продукте.

**Где хранятся заявки?** В localStorage данного origin на данном устройстве. Они не передаются по сети, не проверяют доступность студии и не являются подтвержденным бронированием. Данные можно скачать или удалить; смена браузера или origin не переносит их.

**Что такое Git-коммит?** Снимок согласованного состояния проекта с автором и сообщением. Атомарный коммит решает одну законченную задачу. Префиксы feat, fix и docs объясняют характер изменений.

**Git и GitHub — одно и то же?** Git — локальная распределенная система контроля версий. GitHub — сервис хранения репозиториев и совместной работы. GitHub Pages публикует статические файлы из репозитория.

**Почему GitHub Pages не обрабатывает бронирование на сервере?** Он раздает статические HTML/CSS/JS. Для настоящей записи нужен отдельный backend: база слотов, серверная валидация, предотвращение двойной записи и уведомления.

**Почему SVG и WebP?** SVG подходит для четких масштабируемых иконок; WebP уменьшает размер фотографий. У изображений есть alt и заданное соотношение размеров.

**Как проверить отсутствие горизонтальной прокрутки?** На каждом контрольном размере сравнить scrollWidth корневого элемента с innerWidth и визуально проверить страницу. Также проверить длинные подписи, открытое меню и форму в обеих темах.

## Демонстрационный сценарий
1. Показать реальный URL Pages после публикации; до публикации честно открыть локальный index.html.
2. Показать desktop, затем mobile 390 px: меню, CTA, карточки.
3. Переключить тему в подвале и показать сохранение выбора после перезагрузки.
4. Сравнить цены: vocal 2h без инженера 16,000; с инженером 26,000; mixing 2h 24,000.
5. Попробовать некорректный email, короткий телефон и прошедшую дату.
6. Ввести учебные данные, сохранить, скачать и удалить заявку.
7. Включить аудио и скачать райдер.
8. Показать Figma-фреймы и их сетки после импорта, затем реальную историю git log.
